# Millennium — Lounge & Karaoke

Одностраничный сайт Millennium Lounge & Karaoke: Алматы, проспект Абая, 109/6.
Чистые HTML, CSS и JS без сборки. Подойдёт любой статический хостинг: Vercel, Netlify, GitHub Pages.

## Запуск

```bash
python3 -m http.server 8000
```

Затем откройте http://localhost:8000.

## Что на сайте

- **Первый экран:** название, статус «открыто сейчас» (считается по времени Алматы), кнопки брони и меню.
- **Акции:** оссобуко 5 990 ₸, рибай 3 990 ₸, дымные чаши 3 990 ₸, 20 шотов за 12 990 ₸ (пн–ср), Апероль, «угадай счёт», скидка 15% на день рождения. На телефоне карточки листаются вбок.
- **Меню:** вкладки «Кухня», «Бар», «Кальяны», «Десерты» с ценами.
- **Где сесть:** караоке-кабинки, зал, терраса, футбол, бар.
- **Праздники:** день рождения и девичник, скидка 15%.
- **Бронь:** форма собирает сообщение и открывает Instagram Direct (или WhatsApp, если указан номер).
- **Контакты:** адрес, часы, карта, ссылки на 2ГИС, Яндекс и Google.
- **Навигация:** стрелки вверх и вниз по разделам. На телефоне снизу закреплена панель: стрелки, Direct, Бронь, Маршрут.

## Что поменять

Всё основное лежит в объекте `CONFIG` в начале `js/main.js`:

- `whatsapp`: номер только цифрами, например `"77011234567"`. После этого бронь уходит в WhatsApp, а номер появляется в контактах.
- `aperolPrice`: акционная цена Апероля, например `"2 490"`.
- `hours`: часы работы.

Цены и блюда меню находятся в `index.html`, ищите `class="price"`. Там, где цена неизвестна, стоит `price--ask` («уточняйте»): дорадо, десерты и Апероль.

## Фото

Фото в `images/` взяты из обложек рилсов @millennium_barr. Они в низком разрешении (около 400 px), и надписи из рилсов обрезаны.
Для лучшего качества замените их оригиналами того же имени: `bar`, `ossobuco`, `hall`, `shots`, `karaoke`, `table`, `terrace`, `football`, `birthday`, `bachelorette` (`.webp`, ширина от 1200 px).
